The user authorizes the next implementation with eight explicit acceptance criteria. Work stays under `code/` and prior experiment records remain unchanged.

## Original-domain outer search

List every maximal helper patch from the original Level-3 scope family. Each patch starts with an explicit open assignment root, including patches not reached before termination. Branch over every remaining task in canonical order. A fixed assignment has its sole incumbent owner; a released assignment branches over `None` and the entire fleet. Commitments and all scope masks refer to the original scenario.

Only necessary structural/resource relaxations prune: positive residual mandatory service assigned to no UAV; a chosen fixed-route owner cannot visit its assigned task; a fixed stop contradicts chosen ownership; more distinct assigned tasks than available task slots after reserving the terminal depot; or certified optimistic depot-to-task delivery time exceeds a mandatory deadline. Repeated visits, replenishment and optional zero deliveries remain permitted.

## Cache and replay

Use scenario-bound, immutable cache entries computed from canonical endpoints, vehicle, precision and refinement configuration. Distinguish lower-bound generation from path generation. Every inner call receives a fresh evidence view; it stores only its own used immutable query snapshots. The outer tree similarly stores the lower certificates it consumed. Tests compare cold/warm semantic proof records under sufficient time and fixed node limits, and check cross-scenario rejection and alias isolation. Wall-clock stopping still reports its actual frontier.

Independent outer replay must not import the producer or cache. It checks the complete helper family, raw assignment partitions, every pruning certificate and every attached explicit sequence proof without numerical optimization. Existing quantity/physics proof checkers are the trusted core.
